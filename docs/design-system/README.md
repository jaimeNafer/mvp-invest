# Design System do Lastro

O Design System orienta interfaces consistentes, acessíveis e compactas, preservando a identidade existente. Os cinco componentes fundamentais estão disponíveis; a migração das telas continua gradual: antes de criar um padrão, consulte [fundamentos](foundations.md), [componentes](components.md) e os estilos e componentes existentes. Não suponha que os itens pendentes já estejam implementados.

A interface usa React, TypeScript e CSS próprio. Evoluções devem partir de necessidades reais, preservar regras financeiras e ser verificadas nos estados e tamanhos de tela afetados.
