# Padrões de página

O layout atual usa `Home` para navegação, breadcrumb e área principal. Visão geral usa painel compacto; Carteiras combina cabeçalho, listagem e modal; Operações reúne importação, negociações e saldos; a conferência ocorre no histórico importado. Formulários e painéis devem preservar seus fluxos e dados. Cabeçalhos, filtros, tabelas e detalhes ainda precisam ser consolidados antes de serem tratados como templates implementados.
