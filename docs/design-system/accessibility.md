# Acessibilidade

Use controles HTML nativos, labels associados, mensagens de erro claras e foco visível. Não use cor como única informação de situação ou sinal financeiro. Mantenha navegação por teclado, nome acessível para ícones e retorno de foco em modais. Verifique contraste e navegação nos estados efetivamente alterados; não presuma conformidade WCAG sem avaliação.
