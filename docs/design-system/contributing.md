# Evolução

Consulte os componentes e tokens existentes antes de criar estilos. Prefira composição e extensões justificadas; não crie variantes para corrigir um caso isolado. Documente exceções e mudanças no contrato visual, cubra comportamentos relevantes com testes e valide teclado, foco e responsividade. Não altere cálculos, contratos de API ou regras de negócio para padronização visual.
